性能加速与专属网络代理

接管反重力全量核心进程网络流量，彻底摆脱 Proxifier，并解锁底层 GPU 加速与 8GB 堆内存扩展

反重力专属网络代理通道 (Dedicated Proxy Bypass)
直接接管反重力客户端与语言服务底层流量，无需开启 Proxifier 即可稳定连接 Google 服务
启用反重力专属代理接管
将 Antigravity、language_server、git 等进程流量定向至指定代理节点
代理协议类型
支持主流 HTTP 代理或 SOCKS5 代理网关
代理主机与端口
通常为 Clash/v2ray/Sing-box 本地监听地址 (例如: 127.0.0.1 : 7890)
:
代理绕过域名列表 (Bypass Domains)
不走代理的直连域名，使用逗号分隔
客户端底层运行性能补丁 (Runtime Tuning)
通过注入底层 Chromium 启动标志，大幅提升大工程代码解析与长跑性能
开启 GPU 硬件渲染加速
强制开启 DirectX 12 / Vulkan 显卡硬件渲染加速，大幅消除界面卡顿与滚动掉帧
扩展 V8 引擎堆内存至 8GB (--max-old-space-size=8192)
彻底杜绝大型项目 AST 分析、深度代码索引过程中的 JavaScript OOM 内存溢出崩溃
禁用后台休眠与锁屏降频 (--disable-background-timer-throttling)
防止 Antigravity 窗口最小化或电脑锁屏时智能体任务被系统自动降频冻结
全栈去遥测与日志静默 (--disable-breakpad)
屏蔽崩溃日志上传与不必要的遥测探针，减少后台不必要的磁盘 I/O 开销

任务意外中断自动重试 (Auto-Retry on Error)
